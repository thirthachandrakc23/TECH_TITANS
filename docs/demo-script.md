## 1. Setup (DRAFT)

### Prerequisites to Run the Demo:
- **Node.js** (v18+ recommended)
- Install project dependencies:
  ```bash
  cd frontend
  npm install
  ```
- Start the development server:
  ```bash
  npm run dev
  ```
- Access the application: Navigate to `http://localhost:5173`

> [!NOTE]
> **Camera Access Note:** HTTPS is required for camera access in production environments; `localhost` works for local development.
